Featured solution · Copilot Studio

Case Assistant

Copilot Studio agent for Dynamics 365 Customer Service.

Designed and delivered an AI case-management assistant for a regulatory body's Dynamics 365 Customer Service platform. Case officers can look up, summarise, progress and create cases in natural language from Microsoft Teams, with answers grounded in Dataverse records and the organisation's own knowledge articles.

Microsoft Teams → Copilot Studio → Dataverse + knowledge

Problem

Look up, summarise, progress and create cases in natural language, grounded in the organisation’s own data and the signed-in user’s permissions.

Outcome

Built and published a Copilot Studio case assistant to Microsoft Teams for a Dynamics 365 Customer Service platform. It summarises cases, finds case documents, gives stage-specific next steps from knowledge articles and creates cases through a user-context Power Automate flow with full audit logging.

Case intelligence

Find and summarise a case

By case number, AI-written summary of status, owner, type, key facts, outstanding items, with deep link.

Document access

Find case documents

SharePoint folder and recently uploaded documents.

Stage-aware guidance

Suggest next steps

Reads case type and current business process flow stage, gives stage-specific guidance from a published knowledge article; business users change advice by editing the article, no agent change.

Guided creation

Create a case

Form with lookups loaded from live Dataverse records, confirm, then create.

All four topics run under the signed-in user's security context.

Inside the solution Orchestration, audit & ALM
  • Copilot Studio agent with generative orchestration routing each request to the right guided topic; general knowledge and web search turned off so answers come only from the organisation's own data.
  • Reusable Power Automate agent flow creating records with the user's own permissions; custom Assistant Action audit table logs each action as Completed or Failed.
  • Configured D365 Copilot features in the case app: case summaries incl. custom fields, draft email replies, knowledge-grounded answers with citations, similar-case matching.
  • Stage-based next-step guidance for 10 knowledge articles; scripted reusable test-case load covering every case type.
  • Published to Microsoft Teams; agent, flow and tables packaged in a Dataverse solution in source control, with ALM runbook, logic flowcharts and end-to-end test plan.
